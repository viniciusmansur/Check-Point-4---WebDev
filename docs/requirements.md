A TuxLabsTV tem como objetivo criar um site que unifica os filmes, séries e desenhos assistidos pelos usuários entre diversas plataformas em um só lugar para melhorar a organização das suas mídias favoritas.

O público alvo do nosso projeto são as pessoas que consomem mídias de diversas plataformas, assim dificultando a localização das próximas experiências desejadas.

User Story 1 — Visualizar conteúdos em destaque:
Como usuário do TuxLabsTV, quero visualizar séries, filmes e desenhos em destaque,para encontrar rapidamente conteúdos que sejam do meu interesse.
Critérios de aceitação:
O sistema deve apresentar uma seção de séries em destaque.O sistema deve apresentar uma seção de filmes em destaque.O sistema deve apresentar uma seção de desenhos animados em destaque.

User Story 2 — Acessar listas e informações de contato
Como usuário do TuxLabsTV, quero acessar minhas listas e a página de contato pelo menu de navegação, para consultar conteúdos organizados e obter informações sobre o projeto.
Critérios de aceitação:
O cabeçalho deve disponibilizar o acesso à página Início. O cabeçalho deve disponibilizar o acesso à página Listas. O cabeçalho deve disponibilizar o acesso à página Contato.

Criação de listas personalizadas pelo usuário.

A TuxLabsTV tem como regra ser um produto de fácil uso e acesso.
