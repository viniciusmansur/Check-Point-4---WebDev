Funcionalidades:
Criação de listas personalizadas pelo usuário.
Lista contém pôster, título e sinopse.
Toda vez que a página é atualizada novos filmes aparecem na página inicial.

Tecnologias:
React + Vite
React Router
React Icons
TMDB API
Gemini

Como rodar o projeto:
Clone o repositório e entre na pasta do projeto:
git clone <url-do-repositorio>
cd TuxLabsTv
Instale as dependências:
npm install
Rode o servidor de desenvolvimento:
npm run dev
Acesse http://localhost:5173.

Ou acesse o site pelo link: https://tuxlabstv.vercel.app/


Uso de IA:
O uso de ia no projeto foi para tirar dúvidas e na criação do localStorage para salvar os filmes na lista.
